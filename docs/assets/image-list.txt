HOW TO ADD, EDIT OR REMOVE A PRODUCT
------------------------------------------------
Every product on the site — its name, price, category, description,
stock, and which images it uses — comes from ONE place: data.js.
Open data.js in any text editor and you'll see a list of entries like:

  { "id": "shell-necklace-set", "name": "Shell Necklace Set",
    "category": "necklaces", "price": 2799, "mrp": 3299, ... }

To add a product: copy one whole { ... } entry, paste it as a new item
in the list, give it a new unique "id" (letters/numbers/hyphens only —
this becomes its image file names and its URL, product.html?id=your-id),
and update the name/price/category/description. Then add its 5 images
(1 listing + 4 gallery) to /assets following the naming pattern above.
To remove a product, delete its whole { ... } entry. No other file
needs to change — Home, Shop, Search, Cart and Wishlist all read from
data.js automatically.
